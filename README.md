# 忍者心相录

一个以《火影忍者》角色心理画像为主题的沉浸式性格测试网站。用户可以浏览 30 位角色的心理卷宗，通过 25 道情境题生成八维人格画像，并获得最相似的角色匹配结果。

项目采用原生 HTML、CSS 与 JavaScript 编写，无框架、无构建依赖，可直接作为静态网站部署。

## 主要功能

- 30 位角色心理卷宗展示
- 按阵营筛选角色，并支持姓名或性格关键词搜索
- 角色详情抽屉与八维人格数据展示
- 25 道沉浸式情境测试，包含单选、量尺和多选题型
- 基于意志、共情、谋略、自律、独立、领导、阴影和理想八个维度计算匹配结果
- 桌面端与移动端响应式布局
- 支持键盘 `Esc` 关闭详情或退出测试，并适配减少动态效果的系统偏好

## 本地运行

项目无需安装依赖。进入项目目录后，使用任意静态文件服务器即可预览，例如：

```bash
python3 -m http.server 4173
```

然后访问 [http://localhost:4173](http://localhost:4173)。不建议直接双击 `index.html`，使用本地服务器能更准确地模拟部署后的资源路径和浏览器行为。

## 部署到 Vercel

1. 将仓库导入 Vercel。
2. Framework Preset 选择 `Other`。
3. Root Directory 保持仓库根目录。
4. Build Command 与 Install Command 留空。
5. Output Directory 留空。
6. 点击 Deploy。

仓库根目录中的 `index.html` 会作为入口文件，Vercel 可直接发布全部静态资源，不需要额外构建步骤。

## 技术说明

- 页面结构使用语义化 HTML5。
- 样式完全由原生 CSS 实现，包含响应式断点、过渡动画和 `prefers-reduced-motion` 适配。
- 角色资料、题目、评分和结果匹配均在浏览器端运行，不上传或保存用户答案。
- 唯一的本地图片资源位于 `assets/`；中文字体通过 Google Fonts 加载，网络不可用时会自动回退到系统字体。
- 所有站内资源均使用相对于网站根目录的静态路径，适用于 Vercel 根目录部署。
